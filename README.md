Console application "Restaurant management system"

Описание:
Программа предназначена для управления рестораном.

Функции:
- добавление блюд
- просмотр списка блюд
- удаление блюд
- редактирование блюд
- сортировка блюд по цене
- поиск блюд по диапазону цен
- добавление заказов
- просмотр заказов
- сохранение и загрузка данных в файлы

Используемые технологии:
- язык Pascal (Delphi 11 / Object Pascal)
- структуры данных (связные списки)
- работа с файлами
